# WaferAI 사용 설명서

웨이퍼 결함 분류 서비스 WaferAI 를 쓰는 사람을 위한 안내다. 서버를 설치하고 운영하는 방법은
`deploy/README.md`(운영 설명서)에 있다.

- 주소: https://waferai-demo.eastasia.cloudapp.azure.com
- 기준: 2026-11-17 운영 버전

## 1. 시작하기

### 계정 만들기

1. 로그인 화면 아래의 **가입 신청**을 누른다.
2. 사번, 이름, 이메일, 비밀번호를 넣고 신청한다.
3. 관리자가 승인하면 로그인할 수 있다. 승인 전에 로그인하면 "승인 대기 중"이라고 알려 준다.

권한은 엔지니어로 시작한다. 등급을 올리는 것은 관리자만 할 수 있다.

### 비밀번호 규칙

- 8자 이상이어야 한다.
- 12자 미만이면 영문, 숫자, 한글, 특수문자 중 두 종류 이상을 섞는다.
- 사번이 들어가면 안 된다. 흔한 비밀번호와 같은 글자 반복도 받지 않는다.

### 로그인이 안 될 때

| 화면에 나온 말 | 뜻 | 할 일 |
|---|---|---|
| 사번 또는 비밀번호가 올바르지 않습니다 | 둘 중 하나가 틀렸다 | 다시 입력한다 |
| 로그인 시도가 너무 많습니다. N초 뒤에… | 5번 연속 틀려 잠겼다 (60초부터, 최대 15분) | 기다리거나 관리자에게 잠금 해제를 요청한다 |
| 승인 대기 중입니다 | 가입 신청이 아직 승인되지 않았다 | 관리자에게 승인을 요청한다 |
| 사용할 수 없는 계정입니다 | 관리자가 계정을 비활성화했다 | 관리자에게 문의한다 |
| 요청이 너무 많습니다. 1분 뒤에… | 같은 네트워크에서 로그인 요청이 몰렸다 | 1분 뒤 다시 시도한다 |

비밀번호를 잊었으면 관리자에게 초기화를 요청한다. 임시 비밀번호를 받아 로그인하면 계정 화면으로
이동하고, 비밀번호를 바꾸기 전에는 다른 화면을 쓸 수 없다.

## 2. 권한

| 등급 | 할 수 있는 일 |
|---|---|
| 엔지니어 | 웨이퍼 업로드, 판정 결과 조회, 검토(승인, 수정, 라벨링), 기록 CSV 내려받기 |
| 수석 엔지니어 | 위에 더해 판정 임계값 변경, 모델 관리 조회 |
| 관리자 | 위에 더해 계정 관리, 보안 기록, 서버 상태, 재학습 요청과 학습 데이터 내려받기 |

## 3. 웨이퍼 올리기 (대시보드)

**웨이퍼 업로드**를 눌러 파일을 고른다. 여러 파일을 한 번에 고를 수 있다.

| 형식 | 내용 |
|---|---|
| `.npy` `.csv` `.json` | 0(배경), 1(정상 다이), 2(결함 다이)로 된 2차원 맵. 최대 512×512 |
| `.png` `.jpg` | 그 맵을 세 가지 색으로 그린 그림. 224×224 권장, 최대 8MB |

그림은 색에 따라 다르게 처리한다.

- 학습 색(검정, 초록, 노랑)과 viridis, 회색조는 바로 읽는다.
- 처음 보는 세 가지 색은 추정해서 읽고, 결과는 반드시 검토 대기로 보낸다.
- 실물 사진이나 색이 많은 그림은 받지 않는다.

여러 파일을 올리면 결과 요약 상자가 나온다. 파일마다 판정 클래스와 처리 경로가 보이고, 실패한 파일은
이유가 옆에 적힌다. 줄을 누르면 상세 화면이 열린다.

### 처리 경로 (배지 색)

| 배지 | 뜻 | 사람이 할 일 |
|---|---|---|
| AI 자동 통과 (초록) | 확신도가 기준 이상이다 | 없음 |
| 규칙 확정 · Near-full (보라) | 결함 밀도가 80%를 넘어 규칙으로 확정했다 | 없음 |
| 검토 필요 (빨강) | 확신도가 기준에 못 미친다 | 검토한다 |
| 판정 불가 · 확인 (주황) | 웨이퍼 맵처럼 생기지 않은 입력이다 | 입력이 맞는지 확인한다 |

**기록 CSV**를 누르면 최근 판정 기록을 내려받는다. 엑셀에서 한글이 깨지지 않는다.

## 4. 결과 보기와 검토 (상세 화면)

카드나 대기열의 **상세 보기**를 누르면 열린다. Esc 로 닫는다.

- 왼쪽: 원본, 히트맵, 겹쳐보기를 전환한다. 붉은 영역이 AI 가 판단 근거로 삼은 곳이다. 히트맵은 처음
  한 번 몇 초가 걸린다.
- 오른쪽: 1순위와 2순위 클래스의 확신도를 보고 결정한다.

| 버튼 | 언제 쓰나 |
|---|---|
| 1순위 승인 | AI 판정이 맞을 때 |
| 2순위로 수정 | 2순위가 맞을 때 |
| 수동 라벨링 + 확정 | 둘 다 아닐 때 목록에서 고른다 |

검토하면 대기열에서 빠진다. AI 의 원래 판정은 지워지지 않고, 검토 결과가 이력으로 따로 쌓인다.
"사람 확인이 필요한 이유"가 빨간 상자로 보이면 먼저 읽는다. 색을 추정해 읽었거나 웨이퍼 모양이
아닌 경우다.

## 5. 리뷰 대기열

검토가 필요한 웨이퍼만 모아 보여 준다. 위의 클래스 버튼으로 같은 유형끼리 묶어 처리할 수 있다.
**대기열 CSV**로 목록을 내려받는다.

## 6. 설정 (수석 엔지니어 이상)

| 항목 | 설명 |
|---|---|
| 모델 권장 클래스별 기준 사용 | 켜면 모델이 싣고 온 클래스별 기준으로 판정한다. 기본은 켜짐 |
| AI 확신도 임계값 | 클래스별 기준을 껐을 때 쓰는 단일 기준. 테스트 셋 기준 예상 검토 비율이 함께 보인다 |
| Near-full 강제 판정 밀도 | 결함 밀도가 이 값을 넘으면 Near-full 로 확정한다. 기본 80% |
| 정상 강제 판정 밀도 | 기본은 꺼짐. 켜면 결함 누락이 크게 늘어 권장하지 않는다 |

기준을 높이면 틀린 채 나가는 웨이퍼가 줄고 검토할 양이 늘어난다. 바꾼 값은 이후 업로드부터 적용된다.

## 7. 모델 관리 (수석 엔지니어 이상)

- **운영 중인 모델**: 테스트 정확도와 macro-F1, 학습 분할, 배포 시각.
- **성능 추이**: 최근 12주의 주별 처리 경로와, 사람이 검토한 건 중 AI 판정과 같았던 비율.
- **확률 보정 · 판정 기준**: 보정 전과 지금의 검토 비율, 틀린 자동 통과, 결함 누락.
- **서버 상태** (관리자): 디스크 남은 공간과 마지막 DB 백업. 백업이 36시간 넘게 없으면 표시된다.
- **재학습**: 검토가 500건 쌓이면 작업이 자동으로 생긴다. 관리자가 학습 데이터를 내려받아 GPU 에서
  학습하고, 승격 기준을 넘은 모델만 교체한다. 절차는 `deploy/README.md` 에 있다.

## 8. 계정

- 내 권한과 사번, 마지막 비밀번호 변경일을 본다. 90일이 지나면 변경을 권한다.
- 비밀번호를 바꾸면 다른 기기의 로그인은 모두 풀린다.

관리자는 같은 화면에서 다음을 한다.

| 일 | 방법 |
|---|---|
| 가입 승인 | 승인 대기 행의 **승인** |
| 계정 만들기 | 아래 양식에 초기 비밀번호를 넣어 만든다 |
| 비밀번호 초기화 | **비밀번호 초기화** → 임시 비밀번호가 한 번만 표시된다. 바로 전달한다 |
| 잠금 해제 | 잠긴 계정 행의 **잠금 해제** |
| 비활성화 | 계정을 지우지 않고 막는다. 그 사람의 검토 이력은 남는다 |
| 보안 기록 | 로그인 실패, 잠금, 임시 비밀번호 발급, 가입 승인, 임계값 변경을 최근 순으로 본다 |

## 9. 자주 묻는 것

**실물 웨이퍼 사진을 올릴 수 있나?**
없다. 이 서비스는 전기 검사 결과인 0/1/2 맵과 그 맵을 그린 그림만 판정한다.

**AI 가 틀린 판정을 자동 통과시키면?**
상세 화면에서 수동 라벨링으로 고친다. 검토 결과는 다음 재학습 데이터가 된다. 그런 일이 잦으면
수석 엔지니어가 설정에서 기준을 높인다.

**"판정 불가"가 떴다.**
올린 파일이 웨이퍼 맵 모양이 아니라는 뜻이다. 다이 수가 너무 적거나, 원형이 아니거나, 배경이 없는
경우다. 파일이 맞다면 상세 화면에서 직접 라벨을 정한다.

**확신도 98%는 무슨 뜻인가?**
보정된 값이라, 같은 확신도의 웨이퍼 100장 중 약 98장이 맞는다는 뜻이다.
